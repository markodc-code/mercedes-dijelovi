# Mercedes dijelovi

Program za rastavljanje Mercedesa i prodaju dijelova: prepoznavanje auta po VIN-u,
lista dijelova po grupama (motor, limarija, svjetla…), stanje, cijene, fotke, pretraga i zarada.

- Online: https://markodc-code.github.io/mercedes-dijelovi/
- Lokalno: `Pokreni.bat` (ili `python server.py`) → http://127.0.0.1:8770

Podaci se čuvaju u pregledniku na uređaju na kojem se radi (IndexedDB).
Prijenos na drugi uređaj: Kopija i postavke → Spremi kopiju / Učitaj kopiju.
